# 层压告警值守资料交换

`data/` 收录供演练使用的合成记录，不含真实企业或人员资料。资料使用 UTF-8 逗号分隔，首行为字段名，带逗号的单值用双引号括起。日期采用 ISO 表示，空字段表示来源未填或不适用，不代表数值零。`sources.json` 记录各表列名、身份键和可直接核对的引用。

## 业务资料

- `shifts.csv`：班次和共用派工额度，起止是自当天零时起的分钟。
- `capacity_rules.csv`：日常告警不能动用严重件保留位；delay 表示从责任区间起点算的到场期限分钟。
- `episodes.csv`：复判以当前可见的规则解释工单。from/to 是责任范围，reported 是记录可见时点；空 close 表示未结。
- `signals.csv`：发生与到达均为班次当天分钟，score 来自记录，不是最终标签。
- `dispatch.csv`：实际派工，不代表其他候选会产生同样动作。departure 空表示尚可取消。
- `policies.csv`：可比较的例行候选政策和原值守配置。分数门槛与去重窗分别适用于识别候选和判断同区连续提示。

班开始时保留位包含在总额度中。每班的额度按已出发单累积扣减，班内不重新补充。回放的到场时间用候选的路程时间估计，实际单使用实到。实际工单不会自动成为所有候选的起始派工；需要对实际班复盘时，它们是历史事实。超过反馈窗口仍无确认的非检修区间可列为无已知事件，未结或归属冲突除外。

## 本地核对

资料核对使用 Python 3.11 标准库，无需额外安装。

从仓库根目录执行 `python3 check_sources.py`，返回各表行数；其他同格式资料可用 `python3 check_sources.py 路径` 检查。脚本只读资料并报告结构或引用错误，不给出业务结论。执行 `python3 -m unittest -v` 检查资料约定及拒绝重复身份的行为。
